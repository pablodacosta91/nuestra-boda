# Invitación · Pablo & María del Carmen

Invitación responsive en HTML, CSS y JavaScript. No necesita instalación, compilación ni backend. Los recursos visuales están incluidos y no utiliza fuentes, bibliotecas ni rastreadores externos.

## Publicar en GitHub Pages

1. Creá un repositorio en GitHub, por ejemplo `nuestra-boda`. Para GitHub Free, usá un repositorio público.
2. Subí **el contenido de esta carpeta** a la raíz del repositorio: `index.html`, `styles.css`, `script.js`, `.nojekyll` y la carpeta `assets` completa. No subas solamente el ZIP.
3. En **Settings → Pages → Build and deployment**, seleccioná **Deploy from a branch**.
4. Elegí la rama `main` y la carpeta **/(root)**. Guardá.
5. Cuando finalice la publicación, GitHub mostrará el enlace: `https://TU-USUARIO.github.io/nuestra-boda/`.
6. Abrí ese enlace en el celular y comprobá las ubicaciones y tu mensaje de WhatsApp antes de compartirlo.

Guía oficial: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site
